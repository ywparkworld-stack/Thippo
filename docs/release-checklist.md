## C. staging での通しの確認（Stripe テストモード）

- [ ] CI（lint・型チェック・単体テスト・DB テスト・ビルド）と E2E が main で成功している
- [ ] 会員登録 → メールの確認 → 本人確認書類の提出 → 運営で承認 → 承認メールが届く
- [ ] 本人確認の却下（両面を求める）→ 却下メール → 両面で再提出できる
- [ ] 掲載申込 → 運営で承認 → 招待メール → パスワード設定 → 会社情報 → Stripe のオンボーディング（テスト）→ スペースを登録・公開
- [ ] 予約 → 支払い（テストカード 4242…）→ 確認メール（利用者・貸出主）→ 予約履歴・領収書
- [ ] 同じ枠を2つのブラウザで同時に支払うと、後の方が「他の方が先に予約しました」になる
- [ ] 支払いの画面で15分以上放置すると、注文が期限切れになり枠が空く
- [ ] キャンセル：2時間より前（全額）・2時間以内（半額）・利用開始後（返金なし）の返金額と、Stripe の返金・差し戻し額が仕様どおり
- [ ] 過去24時間に5回キャンセルしたあと、6回目は返金なしになる
- [ ] 貸出主都合のキャンセル・運営判断での全額返金・無断キャンセルの記録
- [ ] 返金の失敗を起こして（テストモードの失敗用カードなど）、運営管理から再実行できる
- [ ] リマインド（前日18:00・2時間前）が届く
- [ ] 月次明細・請求書（PDF）を発行でき、貸出主がダウンロードできる。マイナスの月も発行できる
- [ ] 運営管理：ダッシュボードの数字、利用者・貸出主の停止、スペースの公開停止、操作ログ
